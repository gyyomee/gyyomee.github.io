**측정기준(dimension)**

* 데이터의 속성.  
* 더 나은 분석을 위해 구성할 수 있는 데이터 세트의 속성. 
* 구입, 행동, 전환 행동



**측정항목**

* 정량적 측정 요소.  세션 수 측정항목은 세션 총 세션의 수를 나타냄. 세션당 페이지 수. 측정항목은 세션당 발생한 평균 페이지 조회수.
* 측정 기준과 쌍을 이루기도 하는 데이터 세트에 포함된 숫자.
* 사이트 사용(Site usage):사용자 수, 세션 당 페이지 수, 평균 세션 기간 등 행동 측정항목을 보여준다.
* 목표(Goal) : 사용자가 구성한 목표 개수를 기준으로 측정항목을 보여준다.
* 전자상거래(ecommerce) : 애널리틱스에 전자 상거래 추적을 설정한 경우의 측정항목.
* '사용자' 측정항목이 측정하는것 : 특정 기간에 사이트에서 한 번 이상 세션이 실행된 사용자.



**보조 측정기준(a secondary dimension)**

* 구체적인 분석을 위해 표에 다른 측정 기준 추가.
