SW Expert Academy에서 <a href="https://www.swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AWdXofhKFkADFAWn&categoryId=AWdXofhKFkADFAWn&categoryType=CODE">5550. 나는 개구리로소이다</a> 문제를 해결했다.

* `v`에는 현재 개구리울음 소리를 저장한다. 현재 울음소리의 `a`의 index를 저장해서 비교를 쉽게할 수 있도록 하였다.
* `flag`는 `v`에서 다음 울음소리가 없는 소리가 들어왔을 때 새로 개구리가 우는지 아닌지 검사하기 위한 flag값이다.
* `frog`는 울음을 마친 개구리의 수이다. 그래서 새로 울기 시작한 울음소리일 때 새로운 개구리인지 기존의 개구리인지 확인하기 위하여 사용하였다. 기존의 개구리면 감소시키고 `frog`값이 0일 경우는 새로 울기 시작한 개구리이므로 `answer`값을 증가시킨다.
* 만약 입력값을 모두 읽었는데도 `v`값이 존재할 경우는 이상한 울음소리 이므로 `-1`을 출력한다.
* `v`에 울음소리가 존재하지 않고 새로운 개구리가 아닐경우는 이상한 울음소리 이므로 `-1`을 출력한다.

<pre><code class="cpp">
#include &lt;iostream&gt;
#include &lt;string&gt;
#include &lt;vector&gt;
using namespace std;

char a[] = { 'c','r','o','a','k' };

int main(int argc, char** argv){
    int test_case;
    int T;
    cin >> T;

    for (test_case = 1; test_case <= T; ++test_case){
        string s;
        cin >> s;
        int answer = 0;
        int frog = 0;
        vector&lt;int&gt; v;
        for (int i = 0; i < s.length(); i++) {
            int flag = 0;       
            //현재 개구리 검사
            for (int j = 0; j < v.size(); j++) {
                //울음소리가 존재할때
                if (a[v[j]] == s.at(i)) {
                    flag = 1;
                    //마지막 울음소리일때
                    if (v[j] == 4) {
                        v.erase(v.begin() + j);
                        frog++;
                    }
                    else {
                        v[j]++;
                    }
                    break;
                }
            }
            if (flag == 0) {
                if (s.at(i) == 'c') {
                    v.push_back(1);
                    if (frog != 0)
                        frog--;
                    else {
                        answer++;
                    }
                }
                else {
                    answer = -1;
                    break;
                }
            }
        }

        if (v.size() != 0)
            answer = -1;
        cout << "#" << test_case << " " << answer << "\n";
    }
    return 0;
}
