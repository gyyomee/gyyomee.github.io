# 세키가하라 전투력 계산기 페이지 안내

최근에 2인 전쟁 게임인 세키가하라 보드게임을 해보게 되었는데, 테마도 진행 방식도 너무 재미있었는데 생각보다 잔룰이 많아서 전투력 계산하는 방식이 좀 어렵더라고요.

블록 개수가 많아질수록 문양들도 고려하기 귀찮기도 하고, 다시 리플레이할 때 전투력 계산하는 걸 까먹어서 불편할 것 같아서 전투 시 사용할 수 있는 **세키가하라 전투력 계산기 페이지**를 만들었습니다.

---

## 🚀 사용 방법

사용 방법은 간단합니다.

- 동군과 서군에 블록을 추가하면 자동으로 계산해서 하단에 점수를 보여줍니다.
- **'충성심 흔들기' 카드를 사용할 경우:** 해당 블록을 삭제하고 상대 진영에 '배신자 문양'으로 추가하면 됩니다.
- **배신자 처리:** 배신자의 경우는 중복 문양이 나오지 않을 거라 생각해서 문양 보너스는 없습니다. (특수 병기 보너스는 들어가게 됩니다.)
- **대장 처리 (Tip):** 플레이하다가 알게 되었는데, 각 진영의 대장은 특수한 문양을 가지고 있기 때문에 가문 문양과 다릅니다. 이때도 '배신자 문양'을 이용하시면 될 것 같습니다… ^\_^
  - (보통 대장을 전투에 막 내보내는 경우가 많지 않을 것 같아 자주 사용하지 않을 거라고 여겨서, 약간 몰입도가 깨지지만 그 방법이 편할 것 같습니다.)
- **특수 병기 (조총, 기마):** 조총과 기마 같은 경우에는 블록 추가 후 **한 번 더 선택**을 해줘야 노란색 테두리로 활성화가 됩니다. (일반 공격으로 사용하는 경우도 존재해서 이렇게 만들어 두었습니다.)

---

## 🙋‍♂️ 후기 및 피드백

실제로 플레이하는 데 사용해 보았는데, 전투 속도가 빨라져서 좀 더 플레이 타임이 매끄럽더라고요.

저도 세키가하라 보드게임을 많이 해보진 않아서 잘못된 부분이 있을 수 있는데, 잘못된 부분이 있으면 알려주시면 수정해 보도록 하겠습니다.
